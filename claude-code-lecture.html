Claude Code とは？

基礎知識

Claude Code とは

Anthropic社が開発したAIエージェントです。
ターミナル（黒い画面）に日本語で指示するだけで、ファイルの作成・編集・ブラウザ操作・データ集計など様々な作業を自動でこなします。

💬 使い方はシンプル

私
今日の勤怠報告を Slack の #勤怠チャンネルに投稿して。「9時05分 業務開始」という内容で
AI
了解しました！Slack の #勤怠 チャンネルに「9時05分 業務開始」を投稿しました ✅

  • 1
    Slack・チャットツールへの自動投稿
  • 2
    Webブラウザを自動操作してデータ収集
  • 3
    Excelやレポートを自動生成
  • 4
    テキストを分析・要約・分類

さっそく始めるには

セットアップ
準備するもの（3つだけ）

1️⃣ Claude Code のインストール

ターミナルに 1行コマンドを入力するだけ。
担当者が事前にセットアップ済みの環境を配布する場合は不要です。

2️⃣ Slack MCP の設定

SlackのAPIトークンを1度設定するだけ。
以降はClaude Codeが自動で投稿先を判断します。

3️⃣ 管理画面のID/PW

mjs.train.tracks.run のログイン情報を渡すだけ。
ブラウザ操作はPlaywright MCPが全て自動化します。

注意点とコツ

🔑 うまく使うコツ

  • 指示は具体的に書くほど精度が上がる
  • 期間・チャンネル名・対象者など条件を明示する
  • 出力形式（HTML・CSV・スクショ等）も指定できる
  • 「確認してから実行」と伝えると安全

⚠️ 注意点

  • Slack投稿など外部への送信は取り消し不可なため、内容を確認してから実行
  • 個人情報を含む日報データは社内ポリシーに従って取り扱う
  • AIの判定は参考情報。最終判断は人間が行う
